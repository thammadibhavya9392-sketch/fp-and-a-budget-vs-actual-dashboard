# FP&A Budget vs Actual Dashboard

## Overview

This project demonstrates a Financial Planning & Analysis (FP&A) Dashboard developed in Microsoft Excel for FY 2025–26.

The dashboard provides interactive insights into financial performance by comparing Budget vs Actual values and tracking key financial KPIs.

---

## Dashboard Highlights

- Budget vs Actual Revenue
- Revenue Variance Analysis
- Operating Profit
- Gross Profit Margin
- Operating Profit Margin
- Regional Performance Comparison
- Monthly Revenue Trend
- Monthly Revenue Variance

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Financial KPIs
- Dashboard Design

---

## Business Insights

The dashboard enables users to

- Monitor financial performance
- Identify budget variances
- Analyze regional revenue
- Evaluate profitability
- Support financial planning and decision-making
